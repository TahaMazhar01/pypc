# PYPC Content & Policy Approval Register

**Rule: only approved items may be published.** No placeholder values, invented
statistics, unapproved names or unverified partner claims may appear on the site.
Where something is not yet approved, the site says so in plain language instead of
guessing — that is why the IMUN 2027 page labels planning-stage figures as targets.

**How to use this register**

1. For each item, obtain written approval from the designated authority.
2. Record the approval date and the method (email, minute reference, digital sign-off, signed document).
3. Change Status to `APPROVED` and set the Review Date (normally 12 months on).
4. Store the evidence in the secure document repository.
5. Only then may the item be published or changed on the website.

Status values: `PENDING` · `APPROVED` · `REJECTED` · `SUPERSEDED`

## Approval methods (record one per item)

* Written email from the approver
* Board meeting minute reference
* Digital sign-off recorded on the platform
* Physical document with signature

## Items the platform enforces in code, not by convention

| Rule | Where it is enforced |
| --- | --- |
| Only staff may open the admin panel; a member never renders it, and staff below admin cannot open the members, certificates or payments pages | `ADMIN_PANEL_ROLES` in `lib/auth.ts`, enforced at the edge (`middleware.ts`) **and** in `app/admin/layout.tsx`, then again per API route |
| A certificate cannot be issued without completion evidence | `lib/certificates.ts` issue path |
| Nobody may issue a certificate to themselves | same |
| A revoked certificate stays revoked, with reason and timestamp | `/verify` shows the revocation, never hides it |
| A membership activates only after the gateway confirms or an admin settles | `lib/orders` → `fulfilOrder` |
| Manual settlement is admin-only, needs evidence and is audited | `/api/payments/manual-settlement` |
| Rate limits, origin checks and password policy | `lib/security`, `lib/validation` |
| Contrast and responsiveness thresholds | `npm run check:contrast`, `npm run check:responsive` |
